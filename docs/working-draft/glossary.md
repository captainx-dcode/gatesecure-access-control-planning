# GateSecure Glossary

| Term | Meaning in GateSecure |
|---|---|
| Access point | A controlled entrance or resource, such as an estate gate, apartment door, parking entrance, gym, or swimming pool entrance. |
| Access grant | A scoped permission allowing a person or credential to access a defined location or resource under specified conditions. |
| Access event | A record of a relevant event, such as a request, approval, denial, command, acknowledgement, override, or failure. |
| Authentication | Establishing that a person or system is presenting an accepted credential. |
| Authorization | Deciding whether a person or system is allowed to perform a particular action. |
| Credential | A PIN, app-based credential, card, fob, or other supported mechanism used to present or prove access rights. |
| Estate | A residential property or managed residential community configured as an independent administrative boundary in GateSecure. |
| Estate administrator | A person authorized to manage defined estate-level users, policies, and operations. |
| Household administrator | A person authorized to manage household membership and household-sponsored access within estate policy. |
| Identity | A record representing a person or system, distinct from the permissions granted to it. |
| Least privilege | Giving each role or identity only the permissions needed to perform its authorized tasks. |
| MVP | Minimum Viable Product, the smallest useful product release that can test the core product assumptions. |
| Platform operator | The organization or role responsible for operating and maintaining GateSecure as a service. |
| Resident | A person with an approved residential relationship and corresponding access permissions. |
| Revocation | Ending an access grant or invalidating a credential so it should no longer authorize access. |
| RBAC | Role-Based Access Control, a model that assigns permissions according to roles, combined with additional scope checks where required. |
| Temporary credential | A credential intended to be valid for a limited time or specific approved access grant. |
| Visitor request | A request to visit a resident or unit, awaiting an authorization decision. |
| Verified identity | An identity supported by the verification procedure required for the relevant context; it does not automatically mean access is authorized. |
